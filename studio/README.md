# Финальная система «Мастерская Веры»

Это самостоятельная версия сайта с публичной частью и админкой. Она не зависит от старых HTML-страниц в корне репозитория.

## Запуск

```bash
cd studio
cp .env.example .env
npm install
npm run dev
```

Откройте `http://localhost:4173`. Админка находится по адресу `http://localhost:4173/admin`.

## Что хранит админка

- Жителей, их фотографии, статусы, Хроники и галереи;
- коллекции и оформление Миров;
- истории Мастерской;
- входящие заявки на создание Жителя;
- фотографии и видео, загружаемые сразу в папку конкретного Жителя.

Для маленькой мастерской используется единый JSON-файл данных: он создаётся из `data/content.seed.json` при первом запуске. На сервере следует добавить `studio/data/content.local.json` и `studio/public/media/uploads/` в регулярное резервное копирование.

## Перед публикацией

1. Указать сильные `ADMIN_PASSWORD` и `SESSION_SECRET` в `.env`.
2. Настроить HTTPS и домен на Node.js-сервере.
3. Добавить реальные ссылки на Telegram / Instagram в настройках окружения или в отдельный блок контактов.
4. Не удалять старый сайт до проверки этой версии на телефоне и компьютере.
