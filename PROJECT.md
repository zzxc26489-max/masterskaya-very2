# Контекст проекта «Мастерская Веры»

Мастер-файл для быстрого входа. Обновлять при изменении данных.

---

## 1. Бизнес

**Что это:** авторские фигурки ручной работы из полимерной глины —
драконы, сказочные персонажи, лесные существа. Каждая — в единственном
экземпляре, со своей историей.

**Собственный язык бренда** (важно сохранять в текстах):
- «Жители» — фигурки/персонажи, не «товары»
- «Миры» / «коллекции» — тематические группы Жителей
- «Хроники» — истории уже проданных Жителей
- Обращение к посетителю — «путник»

**Контакт:** через форму на `/contact.html`, самый быстрый канал — Telegram.
Отвечает Вера лично.

---

## 2. Состояние сайта

Сайт уже полностью спроектирован и построен — не черновик, а готовый
продукт с продуманной атмосферой (тёмная тема, реальная предметная
фотосъёмка, авторские орнаменты, эффекты по мирам: снег, светлячки,
туман).

**Технически:** Node.js + Express (`studio/server.mjs`), не статический
сайт. Есть встроенная админка (`/admin`, пароль в `.env`) для управления
Жителями, коллекциями, историями, Хрониками, фото и видео — без правки
кода.

**Страницы:** Главная, Жители (`/residents.html`), Миры
(`/collections.html`), Как создаются (`/process.html`), О мастерской
(`/about.html`), Контакты (`/contact.html`).

**Данные:** `studio/data/content.seed.json` (Жители, коллекции, тексты) +
`studio/data/content.worlds.json` (картинки по мирам). Медиа —
`studio/public/media/`.

### Деплой

- **Локально:** `cd studio && npm install && npm run dev` → localhost:4173
- **Предпросмотр:** GitHub Pages из `.github/workflows/deploy-pages.yml`,
  собирает статический срез `studio/public` (без `/admin`) при пуше в
  `main`. Публично: https://zzxc26489-max.github.io/masterskaya-very2/
  (недоступен для проверки из этого окружения — прокси блокирует
  `*.github.io`, проверять через локальный запуск + скриншот)
- **Прод:** предполагается отдельный сервер с постоянным хранилищем
  (см. `studio/DEPLOY.md`) — Render-превью использует временную
  файловую систему, загруженное через админку может пропадать

## 3. Как работать с этим проектом

- **Не переделывать без запроса.** Сайт уже сильный и цельный по
  дизайну — сюда приходят с конкретными задачами (тексты, SEO, баги,
  подготовка к запуску), а не с «сделай красиво».
- Тот же стек скиллов, что и у «Свой Сервис», можно скопировать при
  необходимости: `.claude/skills/` пока не заведена в этом репозитории.
- Известная мелочь: `npm install` в `studio/` подсвечивает 1
  high-severity уязвимость (`npm audit`) — не проверял детали, стоит
  глянуть перед боевым релизом.
